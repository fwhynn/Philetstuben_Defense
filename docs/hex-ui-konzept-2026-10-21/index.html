Hexwerk – Strategie auf jeder Kante.

Eine Formensprache für die ganze Oberfläche: Jede Aktion ist ein Hex, Gold markiert genau die eine nächste Entscheidung. Das Hauptmenü ist umgesetzt; alles andere ist hier als baubarer Entwurf beschrieben.

01 · Fünf Regeln

Ein Hex = eine Aktion. Was antippbar ist, hat Hex-Form. Informationen (Werte, Texte) stehen in Kapseln oder auf Pergament, nie in Hexen.
Gold nur einmal pro Bildschirm. Die wichtigste nächste Entscheidung: Spielen, Welle starten, Verbessern. Alles andere ist Grün oder Creme.
Creme = Spielmaterial. Handkarten, Turmfenster und die zweite Spielaktion („Neuer Run“) wirken wie Pergament und Holz.
Nebel = noch nicht erreichbar. Gesperrte Funktionen bleiben als graue Hexe sichtbar und nennen ihre Bedingung („ab Welle 35“). Leere Plätze zeigen „?“ wie unentdecktes Land.
Drei Ebenen je Hex: heller Rand, dunkle Rille, gewölbte Füllung. So bleibt die Kante auch bei 45 px lesbar, und der Designer kann jede Ebene einzeln liefern.

02 · Hauptmenü

Variante A · Hex-Blüte umgesetzt im Branch

Gold-Hex in der Mitte, sechs Ring-Hexe Kante an Kante in gleichmäßigem Kreis: Arsenal, Bestenliste, Einstellungen, Duo, Tägliche Herausforderung, Account. Mit gespeichertem Run zeigt die Mitte „Fortsetzen · Welle N“, „Neuer Run“ steht als Creme-Kapsel direkt darunter. Sprache unten links, Impressum/Datenschutz unten Mitte, Patch Notes unten rechts. Hintergrund: zwei Diorama-Inseln aus echten Spielkacheln. Pfeiltasten springen zum Nachbar-Hex.

Erstspieler sehen so von Anfang an, dass es mehr zu entdecken gibt – ohne dass Funktionen versteckt sind.

Variante B · Diorama-Bühne Ausbaustufe mit Designer-Grafik

Wie im Styleboard: links eine gemalte oder 3D-Hexinsel mit Turm, rechts eine kompakte Wabe. Stärker als Bühne für Editionen (Sakura, Halloween), braucht aber die Hintergrundgrafik.

Variante C · Kompakt-Wabe für kurzes Querformat

Zwei versetzte Reihen statt Blüte, wenn die Höhe unter 420 px liegt (Handy quer). Die Gold-Aktion steht links groß, die Wabe daneben.

03 · Spielmodus-Auswahl

„Spielen“ öffnet drei große Hex-Karten statt zweier Rechteck-Knöpfe. Der Text bleibt vollständig lesbar; Gold bekommt erst der Start-Knopf im nächsten Schritt.

04 · Im Spiel

Ressourcen als dunkle Kapseln mit Hex-Kappe oben, Turmleiste als grüne Hexe links, Handkarten als Creme-Karten unten, „Welle starten“ als einziger Gold-Hex unten rechts. Das Spielfeld bleibt die hellste Fläche.

  • Gesperrter Wellenstart: Nebel-Hex mit Text „Erst ein Hex legen“ direkt im Knopf.
  • Kompakte Navigation unter 900 px bleibt in vier Gruppen; die Gruppenknöpfe werden kleine grüne Hexe.
  • Tutorialrahmen folgen weiterhin den echten Zielen; nur die Rahmenfarbe wird Gold #ffe198.

05 · Turmfenster

Pergament-Leiste mit Porträt auf Hex-Sockel, zwei Kernwerten mit Symbol und genau einem Gold-Knopf. Verkaufen bleibt zweistufig, aber sekundär.

08 · Schrift: lizenzfreie Kandidaten

Alle drei Paare stehen unter der SIL Open Font License 1.1: kommerzielle Nutzung, Einbettung in Spiel, Steam-Build und Webseite erlaubt, auch verändert. Bedingungen: Lizenztext beilegen, die Schrift nicht einzeln verkaufen, eine veränderte Fassung umbenennen. Die Vorschau unten lädt die Schriften nur für diese Konzeptseite von Google Fonts. Im Spiel werden sie als WOFF2 selbst gehostet, ohne Google-Server (siehe Rechtliches).
