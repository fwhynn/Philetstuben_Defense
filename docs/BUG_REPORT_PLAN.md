# Zukunftsaufgabe: Fehler direkt aus dem Spiel melden

Status: vorgemerkt, noch nicht implementiert. Aktuell keine Anbindung an GitHub und keine automatische Übermittlung.

Eine einfach erreichbare Bug-Report-Funktion integrieren, mit der Spieler Fehler beschreiben und bei Bedarf einen Screenshot sowie hilfreiche Angaben zur Spielsituation beifügen können.

Vor der Umsetzung dem Nutzer erklären, was GitHub Issues sind, wie daraus nachvollziehbare Fehlermeldungen werden und welche Möglichkeiten es für Spieler mit bzw. ohne GitHub-Konto gibt. Erst danach gemeinsam die passende Anbindung auswählen; GitHub Issues sind eine Option, noch keine festgelegte Lösung.

Bei der späteren Planung berücksichtigen: Vorschau vor dem Absenden, freiwillige technische Angaben, Sichtbarkeit der Meldungen und Schutz vor Spam. Zugangsdaten gehören nicht in den Spielclient. Keine stillschweigende Übermittlung von Spielständen oder persönlichen Daten.
